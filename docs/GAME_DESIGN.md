# Game Design Document — Tactics Mercenary Revival

## Vision
1999~2002 팬택네트 **택틱스 머셔너리**의 쿼터뷰 Vulture PvP 루팅 슈터를  
브라우저에서 플레이 가능하게 **충실히 재현**하고, 원작 자료를 영구 보존한다.

## Core Fantasy
소형 전투기(Vulture)를 타고 높낮이 있는 전장에서 무기를 줍고 상대를 격추한다.

## Pillars
1. **지형 높이** — 고지→저지 자유 하강, 저→고는 오르막 경로 필수
2. **루팅 무기** — 기본 벌컨 + 필드 드롭, 기체별 제한
3. **키보드 아레나** — 순수 키보드(조이스틱 옵션), Ctrl 사격
4. **존 기반 매치** — 맵 선택 → 입장 → 스코어/리젠

## Modes
| 모드 | 설명 | 부활 1단계 |
|------|------|-----------|
| Deathmatch PvP | 유저 간 격추 | AI 봇으로 대체 |
| Battle Field | 시나리오 + 서버 Mob | 이후 단계 |
| Ranking | 랭킹 표시 | 로컬 스코어 |

## Match Loop
```
기체 선택 → 맵 선택 → 존 입장
→ 벌컨으로 교전하며 무기 스팟 선점
→ 슬롯 전환(1–0) / 아이템(Alt+숫자)
→ 격추 점수 · 사망 리젠
→ 제한 시간 또는 목표 킬 도달
```

## Camera & Feel
- 쿼터뷰(비스듬 탑다운), 원작 스크린샷 구도 참고
- 60fps 목표, 탄·폭발 이펙트, 히트 피드백
- HUD: HP, SPEED, score, 무기 슬롯, 미니맵(후순위)

## Non-goals (1단계)
- 원작 서버 프로토콜 호환
- 원본 .spr/.map 바이너리 완전 파서 (연구 중, 에셋은 보관)
- 유료 인포샵 접속 경로
