# Controls — 원작 & 부활 빌드

## 원작 (공식 홈페이지 explain.htm + lang.kor)

| 기능 | 키 |
|------|-----|
| 발사 | **Ctrl** |
| 특수 아이템 | **Space** |
| 무기 슬롯 1–10 | **1–0** |
| 아이템 슬롯 1–10 | **Alt + 1–0** |
| 상태 창 | **S** (토글) |
| 옵션 창 | **O** (토글) |
| 종료 창 | **Q** (토글) |
| 채팅 시작 | **Enter** 후 입력 |
| 팀 채팅 | **F1** |
| 지역 채팅 | **F2** |
| 전체 채팅 | **F3** |
| 확인/선택 | Enter / O (창 컨텍스트) |

### 이동
원작 문서에 **이동 키 표는 유실**. 코드는 DirectInput + `GetAsyncKeyState`, 조이스틱 지원.  
부활 빌드 기본값 (원작 관례 추정, 설정에서 변경 예정):

| 기능 | 키 |
|------|-----|
| 이동 | **WASD** 또는 **방향키** |
| 선회(선택) | 마우스 에임 또는 A/D 스트레이프 |

## 부활 프로토타입 (증언 반영 2026-08)
- 이동: **WASD / 화살키** (조준과 분리 — 스트레이프 가능)
- 조준: **마우스** 연속 각도 (`atan2`, ~1° 수준; 스프라이트 시트는 3°/120프레임 양자화)
- 발사: **마우스 좌클릭** (주) · Ctrl (보조, 공식 문서)
- 무기 전환: 1–0
- 일시정지: Esc / P

## 미해결
- 원작 정확한 이동/선회 키 매핑 (디스어셈블 교차검증 여지)
- 조이스틱 / 모바일 듀얼스틱 조준
