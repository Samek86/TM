# Tactics Mercenary Revival

팬택네트 **택틱스 머셔너리 (Tactics Mercenary / TM)** 완전 부활 프로젝트.

1999~2002 유실 온라인 쿼터뷰 Vulture PvP 슈터의 **원작 자료 보존** + **브라우저 아레나 프로토타입**.

## 무엇이 들어 있나

| 경로 | 내용 |
|------|------|
| `public/archive/` | 원작 스크린샷·아트·오프닝 영상·SFX·클라이언트 추출물·설치본·웨이백 HTML·설계문서 사본 (~280파일 / ~52MB) |
| `public/archive/MANIFEST.txt` | 아카이브 전체 파일 목록 |
| `docs/` | GDD, 조작, 무기, 기체, 맵, 출처, 로드맵 |
| `artifacts/` | 연구 파이프라인 원본 (웨이백 수집 중간본) |
| `src/game/` | 브라우저 아레나 엔진 (높이 지형, 루팅, 봇, Catcher) |
| `src/data/` | 무기·기체·맵·아카이브 카탈로그 |
| `src/routes/` | 플레이 / 자료실 / 설계 문서 UI |

## 앱 탭

1. **플레이** — 기체 3종 · 맵 5종 · 봇 데스매치 · 오프닝 영상
2. **자료실** — 확보한 원작 에셋 브라우저
3. **설계 문서** — 부활 GDD 요약

## 원작 요약

- 쿼터뷰 소형 전투기(Vulture) PvP 루팅 슈터
- 기체: Born Armor, Killers Pot, Sorcerer
- 맵: Jungle, Jungle2, Vil, Z-Desert, Z-Desert2
- 키보드 전용 + 조이스틱, Ctrl 사격, 1–0 무기
- 공개 전체 플레이 영상은 미발견 (logo.mpg 오프닝만 확보)

자세한 출처와 한계는 `docs/SOURCES.md` 참고.
