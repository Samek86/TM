# Controls — 원작 & 부활 빌드

## 원작 (공식 홈페이지 explain.htm + lang.kor)

| 기능 | 키 |
|------|-----|
| 발사 | **Ctrl** |
| 특수 아이템 | **Space** |
| 무기 슬롯 1–10 | **1–0** |
| 아이템 슬롯 1–10 | **Alt + 1–0** |
| 상태 창 | **S** (토글) |
| 옵션 창 | **O** (토글) |
| 종료 창 | **Q** (토글) |
| 채팅 시작 | **Enter** 후 입력 |
| 팀 채팅 | **F1** |
| 지역 채팅 | **F2** |
| 전체 채팅 | **F3** |
| 확인/선택 | Enter / O (창 컨텍스트) |

### 이동
원작 문서에 **이동 키 표는 유실**. 코드는 DirectInput + `GetAsyncKeyState`, 조이스틱 지원.  
부활 빌드 기본값 (원작 관례 추정, 설정에서 변경 예정):

| 기능 | 키 |
|------|-----|
| 이동 | **WASD** 또는 **방향키** |
| 선회(선택) | 마우스 에임 또는 A/D 스트레이프 |

## 부활 프로토타입
- 이동: WASD / 화살키 (정규화, 대각선 보정)
- 조준: 이동 방향 = 기체 전방 (탱크식; 원작 쿼터뷰 뱅기 느낌)
- 발사: Ctrl 또는 Space 또는 마우스 좌클릭
- 무기 전환: 1–5 (프로토타입 슬롯)
- 일시정지: Esc / P
